Yeh Software Kya Karta Hai (What It Does)

Full Desktop 3D Creation, Comparison, Coloring & Export

  • 1
    Image + Prompt Se 3D Model Banata Hai: Aap koi bhi photo upload karo aur/ya text prompt likho (English, Hindi, ya Hinglish mein) — software Gemini Vision aur Three.js engine se multi-part 3D model aur 3D Voxel/Relief mesh taiyar karta hai.
  • 2
    2 Variations (Option A vs Option B) Dikhata Hai: Har generation par aapko 2 alag 3D models side-by-side milte hain. Aap dono ko 360° ghooma kar dekh sakte ho aur jo better lage use choose karke preview & edit kar sakte ho.
  • 3
    Click-to-Paint Color & Material Studio: Sirf plain model nahi! Aap 3D model ke kisi bhi part par mouse click karke usme apna manpasand Color aur Material Finish (Metallic, Gold, Mirror Chrome, Car Gloss, Neon Glow, Crystal Glass, Wood, Matte) bhar sakte ho.
  • 4
    User Khud Apni Gemini API Key & Custom Model Name Daalta Hai: Aap apni khud ki Google Gemini API Key (AIza...) aur koi bhi Custom Gemini Model Name (jaise gemini-2.5-flash, gemini-2.5-pro, ya koi bhi naya custom model ID) add aur select kar sakte ho!
  • 5
    Aasani Se 1-Click Download (.GLB, .OBJ, .STL, .PNG): Banaye gaye colored 3D model ko 1-click mein Blender, Unity, Unreal Engine, Windows 3D Viewer, ya 3D Printing ke liye download kar sakte ho.
  • 6
    AI Refine & Part Inspector: Model select karne ke baad aap har part ka size, position, rotation badal sakte ho ya AI ko bol kar model modify karwa sakte ho (jaise "iske upar wings laga do").
✕

Yeh Software Kya Nahi Karta (What It Does NOT Do)

Important Limitations & Honest Transparency

  • ✕
    Mobile Phone (Android / iOS) Par Nahi Chalta: Yeh koi mobile app nahi hai. Iska workspace, 3D viewport controls, aur `.exe` build sirf Windows PC / Laptop (64-bit) ke liye banaya gaya hai.
  • ✕
    Koi Cloud Backend Ya Hidden Server Use Nahi Karta: Is tool ka koi backend server nahi hai. Aapki Gemini API key, aapke prompts, aur aapke 3D models kisi third-party server par save nahi hote — jo hota hai aapke PC par hi hota hai.
  • ✕
    Browser Par Live Web App Nahi Hai: Yeh website sirf software ki jankari dene aur `.exe` file download karne ke liye hai. Asli 3D tool aapke PC par `.exe` file download karke chalta hai.
  • ✕
    Character Bone Rigging Ya Movie Animation Nahi Karta: Yeh static multi-part 3D models (cars, robots, weapons, drones, props, voxel sculptures) aur PBR materials banata hai — character walk-cycle animation ya physics simulation nahi karta.
  • ✕
    Photogrammetry Laser Scan Nahi Karta: Yeh Gemini Vision + Procedural 3D CAD Primitives (Boxes, Spheres, Cylinders, Extrusions, Lathes, Voxels) ko assemble karke stylized & modular 3D models banata hai.
  • ✕
    Bina API Key Ke Online AI Generation Nahi Karta: Offline/bina key ke aap built-in Dual Presets, Direct Image Voxel Relief, 3D Painting, aur Export use kar sakte ho, par custom AI generation ke liye aapko apni free Google Gemini API key daalni hogi.
